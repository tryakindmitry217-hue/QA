# UI Автотесты для Кабинета Авито (Задание 2.2)

Данный репозиторий содержит автоматизированные UI-тесты (Python + Playwright) для проверки кабинета продавца.

Тесты написаны с учётом динамических данных стенда (не используют жёстко заданные ID или названия).

## Требования

- Python 3.9 или выше
- Операционная система: Windows, macOS или Linux

## Установка и запуск

1. Склонируйте репозиторий и перейдите в его корневую папку:

   ```bash
   git clone <url-репозитория>
   cd <папка-репозитория>
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Установите браузеры Playwright (если они не установлены автоматически):

   ```bash
   playwright install
   ```

4. Запустите все тесты:

   ```bash
   pytest test_ui.py -v
   ```

## Особенности

- Тесты самостоятельно извлекают названия объявлений из интерфейса, поэтому они не ломаются при изменении данных другими пользователями.
- После выполнения тестов, которые изменяют данные (например, редактирование цены), исходное состояние стенда автоматически восстанавливается.
- В случае ошибки тест падает с явным сообщением, что упрощает поиск багов.

## Структура тестов

- `test_search_by_title` – поиск по названию.
- `test_sort_by_date_and_name` – сортировка по дате и названию (все 4 варианта).
- `test_filters_and_reset` – переключатель «Требует доработок» и сброс фильтров.
- `test_category_filters` – фильтрация по категориям (по одной, комбинации, все три, сброс).
- `test_pagination_and_ad_navigation` – пагинация и переход на страницу объявления.
- `test_edit_validation_save_cancel` – валидация, сохранение, отмена, восстановление цены.
- `test_ai_tools` – AI-инструменты (цена и описание).
- `test_theme_switch` – переключение темы на мобильном устройстве.
